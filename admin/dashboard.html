Welcome back, Avinash

Everything you edit here updates the live site instantly, in this browser.

How this works

This Admin Panel saves your changes to this browser's local storage and the public pages read from that storage the moment they load — so edits appear instantly when you (or anyone using this same browser/device) open the site. Because this is a static website with no server or database, changes made here do not automatically appear for visitors on other devices unless you later connect a backend. See "Account & Security" and the message shown after you download your project for the full explanation.
